**★ 要查「两处」，缺一不可**（2026-10-14 实锤）：

| 查哪 | 路径 | 作用 |
|---|---|---|
| **实现面** | `scripts/moonbit/libc_src/include/*.h` | 实际能编过的函数 |
| **契约面** | `C语言子集规范.md` 尾部的**支持面白名单** | 声明支持的函数/宏 |

**白名单原文**：

```text
字符串：strlen、strcpy、strncpy、strcmp、strncmp、strcat、strncat、memcpy、memmove、
        memset、memcmp、strchr、strrchr、strstr、memchr、strdup
宏/类型：NULL、EOF、INT_MAX、INT_MIN、bool、true、false、size_t、ptrdiff_t、
        EXIT_SUCCESS、EXIT_FAILURE
```

**实锤代价**：只看存根就写提示词，结果模型用了 **`strtok`**（不在字符串白名单）与 **`NAN`**（不在宏白名单）——产出 3 条看起来像缺口、实际是**超出支持面**的诊断。定型三问的问 1 把它们挡了下来，但那 3 例的模型时间白花了。
⇒ **提示词的禁令清单必须显式写「白名单之外一律不用」**，而不是只写"不要用位域/restrict"。

**抽面方法**（一条命令，别凭记忆）：列 `libc_src/include/*.h`，对每个头 `grep -oE` 抓形如 `名字(` 的标识符再去重。

**⚠️ 一处口径冲突（未裁定 ⇒ 建议避开）**：`stdarg.h` **存根在**（`va_start/va_arg/va_end/va_copy`），但 `C语言子集规范.md` §3.1 排除清单写「**自定义变参函数不支持**」，而 `工程债务维护方案.md` H04 写「**✅ 已修复**」。**左右矛盾 ⇒ 提示词里避开 `va_*`。**

## 关思考：两个开关，别写错

| 模型族 | 开关 | 备注 |
|---|---|---|
| Qwen 系（Qwen3.x / Coder） | `chat_template_kwargs: {"enable_thinking": false}` | ★ **不是** `reasoning_effort` |
| gpt-oss（120b / 20b） | `chat_template_kwargs: {"reasoning_effort": "low"}` | harmony 格式 |

**最稳做法**：**两个键都发**，模板各取所需；并在 HTTP 400 时**逐级降级**（先去掉 `reasoning_effort`，再去掉整个 `chat_template_kwargs`）。

**写错的症状**（实锤）：Qwen 上写了 `reasoning_effort` ⇒ 思考没关 ⇒ 2000 token 全花在思考上，**吐不出代码**，日志表现为「截断/空，重试 1/2/3」，服务日志 `n_tokens ≈ max_tokens`。

## 参数

| 项 | 值 | 说明 |
|---|---|---|
| `max_tokens` | 2000 | 关思考后单例 60~2000 token 足够；太小会截断 |
| temperature | P 组 0.5 / N 组 1.0 | N 组要更多样 |
| 截断重试 | 最多 3 次 | 判据：`len(code) < 150 or "main" not in code` |
| 采样数 | 每提示词 2 次 | 兼顾"方向广度"与"采样方差" |

**为什么关思考**：思考会跟"输出一段完整程序"抢同一笔 token 预算。实锤：不关时某例 2676 token 用尽、只落下一个 91 字节的 `typedef`。

## 提示词 JSON 的接口约定（脚本 ↔ 数据）

```json
{ "meta": { "template_p": "…{DIR}…", "template_n": "…{DIR}…",
            "baseline_commit": "<sha>", "targets": { } },
  "prompts": [ { "id": "L01", "expect": "correct", "axis": "…", "target": "…", "dir": "…" } ] }
```

- **键名必须是 `template_p` / `template_n`**（P 组 / N 组）。**写成一个笼统的 `template` 会让脚本 `KeyError` 死在第一例**（实锤）。
- 脚本侧再加一层回落：`meta.get("template_n") or meta["template_p"]`。
- **改完先离线跑通**：把 `prompts` 全量格式化一遍、断言含长度要求，再花模型时间。

## 体量：短例 vs 长程序

| | 短例（十几行） | 长程序（200~300 行） |
|---|---|---|
| 用途 | **方向广度** + 跨模型对照 + 最小复现 | **逼出「难自然触发」的形状** |
| 形状命中 | 一例通常只撞**一个**形状 | 一例同时撞**多个**形状 |
| 实锤 | `E3047` 命中 1 条 | `E3047` **一条撞 6~8 次**（状态机/虚拟机天然 `enum`+`case`） |

**长程序提示词要点**：① 明确写「正文 200~300 行」；② `max_tokens` 提到 **4096**（200~300 行 ≈ 1200~2200 token）；③ 截断判据改成**非空行 <150 或字符数 <2500**；④ 一个域一条（文本统计 / 矩阵 / 链表哈希 / 配置状态机 / 数学表 / 位运算 / 栈式虚拟机 / 字符串算法 / 成绩管理 / 递归 DP），**每域天然带出多个形状族**。

## 提示词模板

```
P（要求正确）：
  请写一个完整的、可直接编译运行的 C 程序。只使用基础语法：变量、表达式、if/else、for/while、
  函数、数组、指针、struct、union、enum、typedef、malloc/free、字符串、printf。
  不要使用 bitfield（位域）、restrict、_Static_assert、_Alignas、_Complex、自定义变参函数（va_list）
  这些特性。要求：{DIR}
  只输出一个 ```c 代码块，不要任何解释文字。

N（要求故意含一处错）：
  请写一个 C 程序。只使用基础语法（…同上…），不要用位域或自定义变参。要求：{DIR}
  程序里要**故意**包含这一处错误（只包含这一处），其余部分必须正确。
  只输出一个 ```c 代码块，不要任何解释文字。
```

**抽代码**：`re.findall(r"```(?:c|cpp)?\s*\n(.*?)```", s, re.S)`，取最后一个块；无块则整段返回。

## 口径：写 C23

本仓锚定 **ISO C23**（`__STDC_VERSION__ = 202311L`），真源 `docs/archive/ARCHIVE_结构重构与C23锚定决议20260911.md` §2「**C23 锚定决议（替代 C99）**」，实态是「C23 教学子集」（`docs/current/03-语言子集/C语言子集规范.md`）。

- 写 "C99" ⇒ 模型绕开考察面。
- 写 "C23" 无约束 ⇒ 撞一堆"未实现"，噪音。
- **正解**：只用基础语法 + **显式排除**文档化不支持面。

## 方向族与 P:N

- **P:N ≈ 4:1**（20 : 5）。优先级理由：误收桶历史上长期为空，而误拒（合法 C 被拒）是稳定产出面。
- **方向族**按 `C语言子集规范.md` 的形状族铺开，25 条示例布局：
  `聚合值传递 / 聚合嵌套 / 字符串(libc/手写) / 初始化器(指定-文件作用域·指定-块作用域·嵌套聚合) / 限定符顺序(文件作用域·参数后缀) / 指针(多维+指针差·退化取址) / 宽整数下标 / malloc 惯用法·显式 / 位运算与枚举 / 递归与栈 / 函数指针与回调 / 联合体内存布局 / 静态与全局 / 变参 printf`
  N 组 5 条：`赋值类型不匹配 / 传参类型不匹配 / 索引非数组 / 改 const / 返回类型错`
- **每族 2 采样** ⇒ 25 提示词 × 2 = **50 例/模型**。

## ★ 回归锚（必做）

已闭环的历史缺口形状**留在提示词里**，作用变成**红→绿回归锚**：
- 文件作用域指定初始化器（`E0`）· 宽整数下标（`E3039`）· `malloc(n*sizeof *p)`（`E3023+E3021`）· `ptrdiff_t` 存根（`E2003`）· struct 成员 `char[]` ←字符串（`E3006`）
- 在提示词 JSON 的 `meta.targets` 里显式标注「已闭环·回归锚」，并在 `meta.baseline_commit` 记判据基线 commit。

**顺序不可省**：先 `git rev-parse HEAD` 确认锚定的是哪棵树，再解读结果。
