## 这门课在做什么

一个 8 点的方波，用**离散傅里叶变换（DFT）**拆成 8 个频率分量。程序里没有魔法：两重循环，外层枚举频率 `k`，内层枚举时间点 `n`，把每个采样乘上 `cos(angle)` / `sin(angle)` 累加——累加结果就是该频率的**实部 `re[k]` 与虚部 `im[k]`**，再取模长得到幅值 `mag[k] = sqrt(re² + im²)`。

方波取 `x = {1, 1, 1, 1, -1, -1, -1, -1}`：前半周期 +1、后半周期 -1。它在频域里主要落在奇次谐波上，`k = 0`（直流分量）恰好抵消为 0——这是方波正负对称的直接结果。

## 在 Vitro 里看什么

1. **相量图（polar）**：`re` 与 `im` 是同一频率的实部/虚部两路序列，绘制成从原点出发的射线 + 端点。`k` 每推进一格，两条序列同时多一对元素，相量图就多一根「指针」——这就是复数 `re + i·im` 在复平面上的几何形态。
2. **频谱（spectrum）**：`mag` 单序列画成柱状 + 频率轴刻度。它和相量图**逐帧同步**：同一帧里 `polar` 的第 k 根射线长度，等于 `spectrum` 第 k 根柱子的高度。
3. **索引格（grid2d / cells）**：源数组 `x` 没有声明视图，按默认索引格逐元素展示。三种视图同帧并列，正好对照「时域样本 → 频域分量」。

## 视图声明是怎么来的

本课开头有一段 `vitri-viz` 注释块：

```
series re im -> polar gain=1
series mag -> spectrum
```

第一行把 `re`、`im` 两条序列交给 `polar` 投影器（它要求恰好两条序列：实部、虚部）；第二行把 `mag` 交给 `spectrum`（单序列）。引擎侧词表只约束「几条序列 / 需要几维维度表 / 已知选项键」，**不提供任何绘制**——绘制在宿主里完成。未声明的数组仍按默认 `cells` 索引格画；声明不合法（未知投影器 / 序列缺失 / 条数不符 / 缺维度表）会出错误面板，不静默降级。

这也解释了为什么引擎不需要认识「傅里叶」：`re/im -> polar` 只是一条普通声明。换成 `series a b -> polar`、把变量改名为 `a`/`b`，视图照画——**场景由课程声明，不由变量名猜测**。

## 输出与精度

程序最后把每个频率的 `k / re / im / mag` 打印出来（`%.3f`）。注意 `k = 2` 的实部/虚部打印成 `-0.000`——不是错误，是 IEEE 754 浮点舍入后带符号的零：`double` 的 `sin/cos` 在整数倍 π 附近会给出极小负值，格式化后就是 `-0.000`。幅值 `mag` 已经取绝对值，所以显示 `0.000`。

这也是本课顺带想说明的一点：**浮点数「看起来是零」不等于数值上精确为零**。比较浮点数不要直接写 `==`，要看差值是否落在容差内——这一课的输出就是最好的反例素材。

## 试着改

1. 把方波换成冲激 `x = {1, 0, 0, 0, 0, 0, 0, 0}`：频谱会变得平坦（所有频率幅值相同）——冲激在频域是「全频段等能量」。
2. 把 `N` 改成 16（同时把 `x` 扩展成 16 个元素）：频率分辨率翻倍，观察 `polar` 的指针数与 `spectrum` 的柱子数同步翻倍。
3. 把 `series mag -> spectrum` 改成本课没声明的名字（如 `series nope -> spectrum`）：重新采集后会看到错误面板而不是空图——这是**故意留给你验证 fail loud 的练习**。
