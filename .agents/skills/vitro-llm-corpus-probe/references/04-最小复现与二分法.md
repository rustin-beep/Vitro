# 04 · 最小复现与二分法

定型三问过了之后，**必须交出一个能独立跑通的最小复现**，才能登记。判据：**clang 与 gcc 都 ACCEPT（或都 REJECT），vitro 双臂与它们不一致**，且把源码压到「删任何一行就不再复现」。

## 二分法流程

1. **先取原始生成文件**（`gen50/<model>/<PID>_s<N>.c`）——不要凭记忆重写，**重写会引入你没想到的差异**（本次教训：我手写的重建版全部 REJECT，而原文件 ACCEPT，找了很久）。
2. **逐维削减**，每次只动一维，记录翻转点：
   - 删 `#include` / 无关语句
   - 改函数名 / 变量名 / 参数名
   - `main(void)` ↔ `main()`
   - 空白、拆行、空行（**这一维常被忽略**，但必须试——本次实测它是**无关变量**，试了才能排除）
   - 字面量 ↔ 变量
3. **两点验证**：
   - **稳定性**：同一文件连跑 3 次，结果一致（排除非确定性）
   - **必要条件与充分条件**：把翻转点单独做成两个文件（含它 / 不含它），确认「有则复现、无则不复现」
4. **写进复现表**（`变体 | clang | gcc | vitro-wasm | vitro-native | 结论`）。

## 实例：`print_int` 的二分（可当模板）

```
# 起点（两个模型独立产出，稳定 ACCEPT）
void print_int(int *p) { (void)*p; }
int main(void) { int v = 42; print_int(v); return 0; }

# 逐维削减
改函数名为 f / g / f2 / ff / foo / print / print_x / println / my_print  → 全部 REJECT E3054
只改参数名 → 无影响
只改空白/拆行 → 无影响
只改 main(void)→main() → 无影响

# 收口（9 行，含"有则复现/无则不复现"两点）
void print_int(int *p) { (void)*p; }      /* ACCEPT  零诊断 */
void printx(int *p)    { (void)*p; }      /* REJECT  E3054  */
```

## 复现文件放哪

- 落 `tmp/<批次>/_repro/<名字>.c`，**每条一个文件**，命名带缺口编号（如 `g01_print_int_reserved.c`）。
- 复现表与结论写进 issue 正文；**issue 里不放全量语料**，只放最小复现 + 根因行号 + 冻结快照指纹（`judge_id`）。

## 反模式（都踩过）

- ❌ **凭记忆重写复现**：会漏掉真正触发的那一维（本次首要教训）。
- ❌ **只试一维就下结论**：空白/命名/`main` 签名都可能是无关变量，必须逐个排除，否则会写出错误的定性。
- ❌ **拿未冻结的判据出复现**：被测 exe 漂移时，"稳定复现"四个字不成立。
- ❌ **把 `judge_error` 当发现**：那是判据自身故障，先修判据。
- ❌ **用 `Read` 判断字面量/空白**：涉字面量、BOM、非可见字符**一律看字节**（本次确认无 BOM：文件首字节 `23 69 6e …` = `#include`）。
