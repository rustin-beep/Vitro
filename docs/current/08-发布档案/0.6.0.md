# vitro/engine 0.6.0（2026-09-26 发版件 · 2026-09-27 线上发布）

- **包清单**：0.5.0 基础上新增 **memory / host / vm**（L7 执行层三包，S6 收官批）
  与 **util**（L0 零语义机械件单点，G-1 收口件）；`cmd/run` 端到端 runner 加入
  cmd 工具族。`protocol` 包（S7 批一号）在本版之后入库，随 0.7.0 发布。
- **版本语义裁定：0.5.0 → 0.6.0（minor）**——新增包 + 公共 API；含一处面变更
  `host.HostMemReply.value` 类型加宽 `UInt?` → `UInt64?`（strtol/strtod/llabs
  等 64 位压栈需求；消费方按 `UInt` 匹配需同步调整）。
- **主题**：**执行层收官**——1MB 载体 + MemoryMap 堆状态机（bump + 有界隔离 +
  first-fit）+ `check_access` 单入口受检访问；110 路由表消费侧 + 字节保真输出
  通道 + 100+ VM 无耦合 handler（内存/ctype/math/字符串/转数值/printf-scanf/VFS，
  统一 `HostMemReply`）；135 opcode 穷尽 match 执行器 + `VMSnapshot` Full/Delta
  快照体系 + 检查点管理器 + libc 产物装载；`cmd/run` 三通道端到端（stdout /
  返回码 / 1MB 内存映像）。
- **兼容义务建册（本版起）**：对外面变更携带兼容义务（mooncakes checksum 不可
  覆盖，修复只能递增版本；弃用须给出迁移路径与移除版本）——`moonbit/CHANGELOG.md`
  0.6.0 起建册；版本语义：修复已发布内容 → patch，新增包/公共 API → minor。
- **性能披露（用户拍板：直接披露，双语 README「性能现状」节）**：端到端小程序
  1.42× / 计算密集 fib 1.92×、冒泡 6.32×、嵌套 15.7× / 条件 A 完整引擎 vs
  oracle JIT 10.1×（同机对拍）；全速执行优化规划 0.7.0+（bytecode→wasm-GC
  生成器路线），解释器持续服务单步语义与时间旅行。
- **验收**：发布彩排（干净项目安装 + 全包编译实测）通过；`moon publish` 线上
  200 OK；GitHub push + CI 双绿；线上安装验收全绿（`moon add vitro/engine@0.6.0`
  编译运行）。发布前置（彼时口径）：moon test 全绿 + 十五闸 + facts 双绿；
  clang_direct 层 2 直拍与 vm_diff 双防线同口径——601 例语料 = SAME 596 /
  KNOWN 5 / DIFF 0。
- **本版在架形态 = 协议层（session/protocol/gateway）之前的最后一个基线**；
  S7 起新包留存于 git，发布随协议片收官批统一裁定（见 0.7.0 档案，发布后补写）。
