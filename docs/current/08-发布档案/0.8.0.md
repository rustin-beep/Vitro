- **包清单（0.7.0 基础上净增 4 包，共 24 包）**：`time_travel`（L8，时间旅行
  引擎域：CheckpointManager 全家 + FrameWindow + UnifiedEngine）、

  `cmd/{vitro,compile,step}` 入列 cmd 工具族（共 9 个 executable）。
- **主题：S8 收官（时间旅行与教学智能）+ CLI 出口总账（#37）**——
  ①时间旅行：CheckpointManager 三模式 + FrameWindow O(1) 窗口 + UnifiedEngine
  + Trap 回退改「检查点+正向重放」（消每步 1MB 快照）；②教学智能：43 算法族
  detect+infer 全量（311 条 golden 对拍逐条一致；教学中文文案由引擎生成）+
  diagnostics 教学七元组 + 数据层五表；③CLI 出口：`vitro run/compile/step`
  （三通道全、退出码全表 0-4、`--json` NDJSON 事件流、`-` stdin、`--` argv
  透传）+ `vitro api` 万能单帧（含 `--batch` 批式状态跨帧——全部协议方法
  脚本化）+ 协议契约冻结 [`docs/spec/CLI_PROTOCOL_V1.md`](../../spec/CLI_PROTOCOL_V1.md)；
  ④**compile 帧新增 `algorithm_matches` 字段**（teaching detect wire 出口，
  协议「只增不改」纪律内、「自诞生即可选」豁免旧读者）。
- **破坏面**：无已发布 API 破坏（CHANGELOG 0.8.0 段全为新增/新增字段）。
- **已知边界（诚实披露）**：is_prime/threaded_binary_tree 两族帧标注因 VM
  code_line 基准偏移暂不可得（#34，oracle 同病）；UAF root_cause_hint 因
  trap 文案缺分配行段恒 null（#35，wire 链就绪待文案修复）；两案修复均挂
  0.9.0 脱钩批。

  巨表——[moon#2254]），`MOON_CC=clang` 同构建 29s（用户实测）；运行期不受影响。
- **验证**：全防线零回归（口径与真值以 `reports/facts.json` 为准——vm_diff 全量
  DIFF=0 / clang_direct 全 KNOWN / shadow 全绿 / serve_smoke 双臂全绿 / demo_smoke
  全绿 / cmd/lib/cli 白盒锚全绿；台账 28 条 diff_ledger PASS；facts strict 0；
  surface -check +2 新边）。
