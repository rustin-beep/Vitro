# moonc 警告全表（2026-10-09 留档）

> 来源：`moonc check -warn-help`（moonbit 工具链官方输出，93 项 + `all` 汇总项）。
> 再生：`cd moonbit && moonc check -warn-help`。若工具链升级后表变，以再生命令输出为准并更新本档。
> 三态：`warn` = 默认启用 · `error` = 默认即强制 · `off` = 默认关闭（`+`/`@`/`-` 可改）。
> `--warn-list` 语法：`+<spec>` 启用 / `-<spec>` 关闭 / `@<spec>` 启用并升为错误 / `<num>` 单号 / `<n>..<m>` 区间。

## 与本仓的关系

- 消警与严格度开启的总账 issue：[#54](https://github.com/rustin-beep/Vitro/issues/54)（Part A 清零批 / Part B 严格度路线）。
- as_of 2026-10-09（A1 机械批落盘后）：`moon check --target all` = **310 条**，分布 0079×217（永久豁免）/ 0035×26（归 #46 合并处置）/ 0020×18（`inspect` 系测试 API 依赖 core 旧 trait——迁移期噪音豁免，见 `moonbit/AGENTS.md` 发布流程注）/ 0029×17、0002×12、0001×10、0007×6（A3 人工判断批待办）/ 0050×2（有意遮蔽，登记 core 升级时复核）。
- 本表存在的意义：Part B 按 `@<spec>` 升错误时需要官方 id/mnemonic 对照，避免每次现查。
