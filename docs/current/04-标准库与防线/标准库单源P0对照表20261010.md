## 2. 必答三题

### ① 病 11 过渡路径（已收编臂如何被 stdlib 吸收）

- **现状链**：`libc_table` 57 条（kinds 非空 28：putchar/puts/strlen/strcpy/strdup/strcmp/strcat/atoi/strncat/strncmp/memcmp/strchr/strrchr/strstr/memchr/atof/atol/srand/tan/log10/fabs/ceil/floor/round/fmod/free/memset/exit）→ `@libc.sig_of` → `check_builtin_table`；visit_call 56 臂名中其余 25 走专臂方法。
- **吸收方式**：`stdlib.sig()` 从 `libc_table` **反向提取，57 条零作废**；`param_kinds` 的 `P/I/D` 字符编码换枚举（`check_builtin_table` 内 `k==80/k==68` 魔数同步消灭）；入口改 `import stdlib`。
- **验收线**：重排前后 typeck_diff hash 等价（与病 11 验收同口径，设计稿 §3.5）。
- **第二层停手建议维持**（§8 裁定项）：kinds 非空 28 > 已切 table 的 15 臂名——第二层正在半途（填了值未全切臂），**恰好是停手的最佳时点**：剩余填值工作并入 stdlib 一次做。

### ② 遮蔽名单处置（实测 17 名，非 route.mbt 头注的 20）

集合运算实测：`idx(88) ∩ host(110) = 22`，`− 改判 5 = 17`：

```
abs, atoi, isalnum, isalpha, iscntrl, isdigit, islower, isprint,
isspace, isupper, isxdigit, rand, srand, strcmp, strlen, tolower, toupper
```

- **与 C3 历史实例对上**：当年「14 臂不可达」= ctype 11 + abs/rand/srand，现已含 atoi/strcmp/strlen 共 17。
- **处置建议（P2 执行）**：这 17 名 bytecode 版与 host 版语义等价（纯函数/无诊断面），实际路径恒 bytecode——host handler 属**写而不可达死面**，建议**随 binding() 生成实际路径表后删**；`shadowed_host_names()` 保留为断言（删后清单应清零，闸即转红——死面消灭的机器证据）。
- **副产物勘误**：`route.mbt` 头注「20 个静默遮蔽」是 2026-10-06 改判 3 条（交集 25→22）前的旧口径，未随改判连坐——**应改 17**（修不修随 P2 批顺带，本批不动他人文件）。

### ③ 宏两分边界清点

| 侧 | 清单（实测） | 新归 |
|---|---|---|
| **预定义**（lexer 常在，不依赖 include） | 对象宏 23：stdout/stderr/stdin/EOF/EXIT_SUCCESS/EXIT_FAILURE/RAND_MAX/SEEK_SET/SEEK_CUR/SEEK_END/INT_MAX/INT_MIN/LONG_MAX/LONG_MIN/CHAR_BIT/SCHAR_MIN/SCHAR_MAX/UCHAR_MAX/SHRT_MIN/SHRT_MAX/USHRT_MAX/true/false；函数宏 4：va_arg/va_copy/va_end/va_start | `stdlib.macro_def` |
| **头文件**（include 后由 pp 解析） | 24 个 #define：float.h 13（DBL_*/FLT_*）+ errno.h 5（EACCES/EDOM/EINVAL/ENOENT/ERANGE）+ stdarg.h 4（va_* 函数式展开）+ assert.h 1（assert）+ time.h 1（CLOCKS_PER_SEC） | 留 `.h` |

- **新发现盲区（P1 批已读码定案 2026-10-10）**：`va_*` **同名字两处定义**——`stdarg.h` 用 `#define va_start(ap,last) __vitro_va_start(...)`（展开到辅助函数），`builtins.mbt` 用 token 预定义（显式 token 列表）。**定案**：`Pp::new` 初始化即装 `builtin_macro_table()`（预定义兜底——不 include stdarg.h 也可用），include 后 `.h` 的 `#define` 走正常 `define_macro` 通道**覆盖**同名预定义——两处都可达、按 include 切换，**非死数据**；stdlib 迁移时 `va_*` 4 条随预定义面走（`macro_def`），`.h` 版本留 surface，语义同构（均展开到 `__vitro_va_*` 辅助函数）。
- **边界判据建议**：「出现在空壳/近空壳头（limits/stdbool/stdint）的宏 = 预定义」——空壳头机制本身是教学子集的有意设计（头文件存在性检查 + 宏预定义），应在 `C语言子集规范.md` 补一段。
