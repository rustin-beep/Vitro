# 语料生成防线方案——五路防线与三段管道

> **as_of 2026-10-12 · 方案已拍板（[#74](https://github.com/rustin-beep/Vitro/issues/74)，经用户 P1/P2/P3 三级实测审计修订），批次未开工。**
>
> **与在册件的关系**：[#25 前件](实机勘探语料扩充方案——许可分流与gcc分桶裁判.md)（2026-10-02）管「**语料从哪收**」（许可分流 / 语料梯队）；本件管「**语料怎么造**」（生成来源 / 变换引擎 / 驱动分桶 / 防线归属）。LLM 生成线（[#73](https://github.com/rustin-beep/Vitro/issues/73)，S2 通道）的探针与方向库计划与本件三段管道对接，分工见 §二。
>
> 本件数字均为 2026-10-12 亲跑实测（spike 40 例，`--std=c --omp-simd=off`），易漂数字带时点口径。

## 一、五路防线全景

| # | 防线 | 状态 | 覆盖的独特盲区 |
|---|---|---|---|
| 1 | 真实场景 ↔ clang（`realcode_diff` 金样本 407 份） | 在役 | 真实代码踩到的 |
| 2 | **合法随机 ↔ clang（路 B，S1 供给）** | **本件新建** | 「没人会写的 C」——seed 决定的合法组合 |
| 3 | 白盒不变量（路 A `fuzz_invariant_wbtest`：UAF/E3060、double-free/E3061、溢出/E3070） | 在役，原位不动 | 恶意输入必报错（S9 判定书分工） |
| 4 | **错误随机 + 痛点定向（路 D/E，突变器 + S2 供给）** | **本件新建** | 学生真实错误分布（现状覆盖全靠手写锚 + 实机反馈） |
| 5 | 单元 + Go 防线自检（四层 diff / host_contract_map / 语料义务链） | 在役 | 引擎内部一致性 |

关系口径：**输入分布互补、机制同源**（#1/#2 同走 clang 对拍）。路 A/B 分工沿 S9 判定书原文：A 管「恶意必报错」，B 管「合法必答对」。

## 二、生成来源三分（S1/S2/S3）

| 来源 | 造什么 | 判什么 | 承担 |
|---|---|---|---|
| **S1** yarpgen（pin `1adb290`，Apache-2.0，黑盒 exe） | 「非人样 C」——no-UB 是设计出来的 | **算没算对**（运行期输出对拍） | 路 B |
| **S2** LLM 本地模型（方向分发，#73 线） | 「人样 C」——工业 C 习惯 + 师生错误形态 + struct/指针/字符串/IO 等上游结构上到不了的形状 | **认不认**（接受/拒绝 + 诊断层；**不进运行期对拍**——UB 率高防假分叉，U 族由 D-U1 方向验证后另议） | 路 D/E + 路 B 诊断层 |
| **S3** 既有语料（`corpus/*.c` 实测 744：baseline 411 / gap 19 / knr 81 / leetcode 138 / codegen_skeleton 13 / template_generated 82；`*.cpp` 83，as_of 2026-10-12） | 回归基线、突变/痛点的变换基底、锚 | 五路既有位置 | 全部 |

核心一句：**S2 造「人样」、S1 造「非人样」；S2 判「认不认」、S1 判「算没算对」。**

## 三、三段管道（按数据流角色切分）

```
基底段（供给）：S3 既有语料 + S1 yarpgen 产物
                     ↓
变换段（Go 统一引擎 corpus_engine，策略表 JSON 外置，token 级）：
  trim（剪枝归一）│ random（突变随机，路D）│ misconception（痛点定向，路E）
                     ↓
驱动段（Go）：clang 判合法 → 分流 → 对拍 / L0-L2 断言 → 统一分桶 → #33 五路台账
             + 并发进程池（Go 职责；批 6 挂既有 schedule 夜间通道）
```

**剪枝规则（外部，T4 已降级待 A/B 验证）**：

| # | 规则 | 保真级 |
|---|---|---|
| T1 | 三词整型去尾 `long long int`→`long long` | L1 拼写等价（无损） |
| T2 | const 后缀转前缀 `int const`→`const int` | L1 拼写等价 |
| T3 | `size_t`→`unsigned int` | L2 条件无损（实测 size_t 仅 driver 模板使用） |
| T5 | max/min 语句表达式宏 → 三元宏 | L3 近似——实参含副作用即丢例，分叉归因嫌疑名单 |

**策略表 schema 要点**：`scope`（code/string/comment 作用域）、`expect.verdict` **四值域 `{error, warn, hint, accept}`**（忘 `&`→W3063、off-by-one→H3069 是合法 warn/hint 出口，不误杀）、`mode`（三模式分节）。`axis` 字段已删（misconception 的 M 编号是 trap 关键词模式，非源码形态轴，不挪用）。

## 四、驱动段：四裁判、分桶、断言

- **四裁判**：clang + gcc + vitro wasm + vitro native——**双端强制**（全域纪律第 14 条，两次实锤）；gcc 分桶裁判已**正式纳入**（随 #25 前件 §2.4 接线，golden 只来自 Clang 不变）。
- **分桶**（severity 降序）：`vitro_accept_clang_reject`（**误收**，教学最坏病）与 `crash/panic`（J8）与 `arm_divergence`（wasm≠native）并列最高 → `mismatch`（归因查 T5 嫌疑名单）→ 缺口桶（误拒合法 C）→ `diag_mismatch`（级别错）→ 资源/超时桶（容量边界、解释器性能，非缺陷）。known 指纹复刻 `clang_direct --check-known` 的 case+digest 双向监控形态。
- **断言五级**（非法池）：L0 不崩不 panic / L1 有诊断出口（四值域）/ L2 码域合法 / L3 类别一对多映射（clang 类别 → Vitro 码集合，实测采样建表）/ L4 位置数量（#50 延伸，不承诺）。
- **双指标口径**：`compile_survival`（clang+vitro 双 accept）≠ `output_match`（运行逐字节一致），分别锚定。基线：spike 40 例粗剪后 **42.5%**，修 E3039 后预估 **~92%**（推算值；残差实测 52×E3039 + 9×E3040 全为级联，修复应同消）。

## 五、已定裁定（2026-10-12，不重开）

1. **永不移植 yarpgen**：反目标论证（撑大子集要求语料来自子集之外，只生成子集内程序的生成器测不到「我们还不认的东西」——恰是路 B 唯一价值来源）+ S2 已建承担形状宽度 + 参数面即数据。黑盒 exe + 外部剪枝，**永久关闭**。
2. **方向库单源、两个消费端**：A 册 = `catalog.json` 104 码 × 238 条 `common_causes`（现成、成本零，管回归）+ B 册 = catalog 之外的实机病例与 clang 反推（管发现）——LLM 方向分发消费它生成程序，`misconception` 模式消费它做定向突变。**只用 A 册 = 假发现面**（每条都命中已实现码，只验证已知规则）。
3. **双端强制**：全域纪律第 14 条（AGENTS.md）。
4. **gcc 正式纳入**：判官席四裁判，非第二真值。
