## 5 · 取真值（探针；**[Rust oracle 退役 2026-10-05]**——原「oracle CLI」整节改写）

```bash
mkdir -p tmp/review_YYYYMMDD && cd tmp/review_YYYYMMDD

# Clang 真值（编译原生 exe 直跑）
printf '#include <stdio.h>\n#include <math.h>\nint main(){printf("%%.17g\\n", fmod(2.0,7.5));return 0;}\n' > p.c
clang p.c -o p.exe && ./p.exe

# Vitro 侧（统一入口；脚本消费一律 --json）
scripts/bin/vitro run p.c --json
scripts/bin/vitro api compile '{"source":"..."}'

# 指令流（CallHost vs Call 10xx）——api/compile 只覆盖诊断面（帧无 code 键），
# 指令流必须走 dump_compile：产物 = {"ok":..,"dump":{...,"code":[...]}}（14 键）
cd moonbit && moon run --target native cmd/dump_compile -- <dir> <outdir> && cd ..
python -c "import json;d=json.load(open('<outdir>/<name>.json',encoding='utf-8'));[print(i['op'],i['operand']) for i in d['dump']['code'] if i['op'] in ('CallHost','Call')]"
```

## 9 · 平台 / 环境速查

| 事项 | 取法 |
|---|---|
| bash PATH | `export PATH="/usr/bin:/bin:$HOME/.moon/bin:$PATH"` |
| 取浮点真值 | 读**原始响应文本**（`"value":\s*([^,}]+)`）；`json.loads` 再 `dumps` 会改写成 repr |
| 两侧比字节 | 先过 `go run ./scripts/canonicalize`（键排序，数字形态不归一） |
| 判 git 忽略 | `git check-ignore -v <path>`（父目录被忽略时 `!` 放行子目录**不生效**，必须实测） |
| 判文件是否有裸 NUL | `python -c "d=open(p,'rb').read(); print(d.count(b'\x00'))"` |
| 判行尾 / 编码 | 一律看字节，别信 Read 的渲染 |

## 10 · 常用口径

| 概念 | 口径 |
|---|---|
| 测试数 | 裸总数 = 逐包之和 + 根 README doc test；与各处 README、`reports/facts.json` 对账 |
| `moon test -p <pkg>` | 报的是**单包**数，不是全仓数 |
| 真值源 | Clang 直拍（golden + clang_direct）；Rust oracle 已退役，档案 tag `rust-oracle-freeze` 按需取回（**[Rust oracle 退役 2026-10-05]**，方法见总计划 §11） |
| `moon check` warning | 不卡 CI；CI 的 fmt 步是 `moon fmt` + `git diff --exit-code` |
