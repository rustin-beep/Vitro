## 一、时间旅行（time_travel 域，L8）

程序执行不再是一次性的：引擎在循环边界自动建检查点（smart 模式），支持**任意步回溯 /
正向重放 / 越窗 seek**，每一步带完整执行现场（调用栈 / 局部变量 / 内存快照 / 输出游标）。

- **帧语义**：协议 v0.1 的 `StepPayload` 十四字段（[schema](../../spec/STEP_PAYLOAD_SCHEMA_V0_1.md)）——
  `semantic_label`（14 类受控词表：循环/交换/递归/函数调用/内存分配释放…）+
  `algorithm_step`（算法阶段教学文案）+ `vis_events`（可视化事件行）+
  `local_vars` / `call_stack` / `array_snapshots` / `pointer_snapshots`。
- **检查点体系**：CheckpointManager 全档/增量/智能三模式 + pinned 隔离区 +
  O(1) 摊还 FrameWindow（窗口 2_000 帧默认）；trap 回退 = 最近检查点 + 正向重放
  （消每步 1MB 快照，常态 O(1)）。
- **入口**：`step.begin / step.next / seek / payload.get / breakpoints.set`
  五方法（gateway wasm-gc 与 serve 双宿主同协议）；CLI `vitro step --json` 一次性帧流。

## 三、diagnostics 域（L8）

诊断不止报错：每条错误带**教学七元组**（fix_suggestion / category / one_liner /
related_lines…），数据层五张表外置 JSON（ misconception / learning_path /
auto_fix / patterns / concepts）+ 机制层（graph 依赖图 / learning_path 学习路径）。
出口：serve `diagnostics_probe` + compile 帧 `fix_suggestion` 字段（CLI --json 同源）。
