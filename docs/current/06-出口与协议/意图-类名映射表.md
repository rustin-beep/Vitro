# 意图→类名映射表（TimelinePlan 三端执行器登记）

> 状态：**v0.2 现行**（2026-11-15，动效编排下沉批四，refs #470）。
> 上游真源：[TimelinePlan Schema v0.2](../../../moonbit/docs/spec/TIMELINE_PLAN_V0_2.md)
> （`moonbit/timeline/plan.mbt` 单源生成）。
> 本文档是**执行器侧登记单源**：plan 字段只表示「意图」，类名 / DOM 属性 /
> 像素 / 时长是各宿主自己的执行器决策。三端各有一份映射实现（窄化不可根除），
> 本表登记三份的现行形态，防「同一意图在三端各叫各的」静默漂移。

## 0. 判据与边界

- **引擎出意图**：`sw` / `cap` / `ch` / `bar` / `cam` / `enter`（见 spec §2）。
- **执行器决定**：类名表、DOM 属性、像素下限、动画时长 / 节拍门 / reduced-motion、
  相机几何。关掉动效后语义仍在（静态类名恒在）——动效预算只关「动」，不关「语义」。
- **映射表登记不等于实现共享**：改任一端映射必须同步本表；表外新增意图字段时
  须在本表补行（或显式登记「该端不消费」）。

## 1. 三端映射总表

| plan 字段 | MCP 静态壳层（`cmd/mcp_js` PLAYER，static） | MCP interactive 壳层（同 PLAYER，LIVE 分支） | demo（Svelte） |
|---|---|---|---|
| `sw{name,i,j}` | 归属数组的 `i/j` 格加 `class="cell swap"`（两格）；其它格按 `ch` 判 `changed` | 同左（`planStep` 页内镜像按 live 帧实时产 plan，同函数两语言） | `ArrayCells`：`.vr-cell.is-swap-event`（两格）、`.vr-swap-link` 连线、`.vr-cells[data-swap="i-j"]`、图例 `[data-swap-legend]`、块头 meta 文本「本帧交换 name[i] ↔ name[j]」 |
| `cap{t,w,dur}` | `#cap` innerHTML = `cap.t`（+ 算法步 `as` + 根因 `⚠` 附加段）；`w/dur` 供宿主节拍（当前壳层读 `w` 语义，时长用 `S.speed`） | 同左（cap 读 `planStep(fr).cap`） | `ArrayCells` 块头 meta 在无交换时显示「当前比较 …」；无独立字幕条组件（`cap.t` 未渲染——登记缺口，见 §3） |
| `ch{name:[idx]}` | 非 sw 格且 `idx` 命中 → `class="cell changed"`（**换源：不再自算前后帧差分**） | 同左（镜像 `ch`，基准 = live 帧流前一帧） | 语句级 `changed` 由宿主差分承担（`.vr-cell.is-swap`，基准 = 相邻**可视帧**——spec §2.3 消费边界）；`insn` 粒度可由 `planAt(...).ch` 承接（待接线，登记缺口） |
| `bar{name:[ratio]}` | 格底 `<span class="bar">` 高度 `--v: ratio`（CSS `height: calc(var(--v)*30%)`；**换源：不再 parseFloat+max**） | 同左（镜像 `bar`） | `ArrayCells` `.vr-bar` 高度 `round(max(ratio*16, 2))px`（像素下限宿主；有 plan 用 `ratio`，无 plan 回退同式宿主归一——旧产物兼容面） |
| `cam{fit,func,depth}` | 不消费（壳层无调用树 UI） | 不消费 | `CallTree` 相机当前按「当前帧节点」跟随（D2 既有语义）；`plan.cam` 已下发并登记为后续批的相机意图（不改变现有跟随行为） |
| `enter:"func:<name>"` | 不消费（无进场 UI） | 不消费 | 不消费（函数进入的视觉表达由调用树过渡承担） |
| `enter:"diag:<category>"` | 不消费 | 不消费 | `RootCauseNote`：`class:is-enter` + `data-enter`（根因卡 rise 入场；reduced-motion 由 app.css 全局规则切断） |

## 2. 各端行为闸（映射的机器锚）

| 端 | 闸 | 断言点 |
|---|---|---|
| 静态壳层 | `timeline_equiv`（CI cli_smoke） | 同一产物逐帧：交换帧集合 / swap cells / changed cells / 字幕 HTML 旧规则 ≡ plan 路径 ≡ 真实 DOM |
| 静态壳层 | `mcp_smoke`（CI cli_smoke） | `doc.timeline` 不变量 + PLAYER 驱动 `cell swap` 锚 + **EMBED 镜像 == 引擎 plan 逐帧全字段** |
| interactive 镜像 | `mcp_smoke`（静态产物内同一 `planStep` 函数） | 镜像在产物帧集上重算 == 引擎 plan（sw/cap/ch/bar/cam/enter）；真 live 路径由本地 accept / 浏览器实测覆盖 |
| wasm 产物 | `timeline_wasm_anchor`（CI serve_channel） | wasm 臂 `timeline.plan` 内容不变量（pv/ch/bar/cam/enter） |
| demo | `e2e_session`（D1/D1b/D3） | plan 链路（planPv/planSteps/planSw/planBarLen/planCam0）+ 交换双格/连线/meta/图例 + 多数组归属 + 双数组计划表 + bar 高度 |
| demo | E-08 golden（`rootcause-uaf`） | 根因卡 DOM 逐字节锚（无 plan 的 SSR 形态） |

## 3. 已登记缺口（不假装已接线）

1. **demo 无 `cap` 字幕条**：`cap.t` 在 demo 工作台没有独立渲染面（块头 meta 只
   显示交换/比较摘要）。批三把 meta 换源到 plan.sw 后，字幕原文仍由宿主语义
   标签决定；若要字幕条，需 UI 设计批另立（不在本映射表强行发明）。
2. **demo `insn` 粒度 `ch` 未接线**：`planAt(...).ch` 已可得；`ArrayCells` 的
   `changed` 仍走宿主差分（语句级基准语义不同，见 spec §2.3）。insn 粒度可
   后续批切换。
3. **demo `cam` 未消费**：字段已下发（E2E D1 断言 `planCam0`），`CallTree`
   相机沿用 D2 现行语义；独立相机批再做。
4. **壳层 `cam/enter` 不消费**：MCP 壳层无调用树 / 进场 UI（诊断卡级联已有
   独立动画，不经 `enter`）。
