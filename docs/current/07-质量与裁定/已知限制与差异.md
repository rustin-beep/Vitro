# 已知限制与差异（as-of 0.7.0）

> 本清单是 vitro/engine 的**主动披露**：四类条目——已知缺陷（将修）、教学语义设计（有意为之，不是缺陷）、与 C 标准/Clang 的已知差异（架构决定）、路线图缺口（按片排期）。每条标注 Clang 对照状态（`Clang 一致` / `Clang 不一致` / `无 Clang 对应`——Vitro 私有语义）与处置轨道。
>
> **这不是「修不了」的清单**：第 ② 类是我们的产品语义（Clang 在同样输入下直接未定义行为，Vitro 给出可教学的诊断）；第 ① 类已排修复轨道（0.8.0 脱钩批——「照搬 Rust oracle」期结束，存量逐项清）；第 ③ 类是白箱 32 位内存模型等架构决定的连带，改它们等于改架构。
>
> 真值锚：[Clang 直拍防线](../02-构建与上手/脚本总清单与必跑防线.md)（696 例逐例对照，689 一致 / 7 条已归因登记 / 0 未预期差异）；机器单源化已启动（2026-09-30 S8 批零号一段 a）：**差异台账单源 = `scripts/diff_ledger/ledger.json`**（初始 14 条 = 蓝图 §⑦ 快照迁入，`DIFF-*` 编号在册的条目此处标注）；本清单随台账复核批（一段 b）演化为台账的人工导读层。

## ① 已知缺陷（将修——0.8.0 脱钩批逐项清）

这些是**真缺陷**：与 C 语义或 Clang 行为不一致，且无教学理由。历史上为保持与 Rust oracle 逐字节对拍而照搬登记，脱钩批修复。

| # | 条目 | Clang 对照 | 位置 |
|---|---|---|---|
| 1 | **printf 旗标/精度三偏差**〔DIFF-LIB-PRINTF-01——四偏差面定稿（2026-09-30 探针实锤）：旗标×2 + 精度 + %*d 动态宽度 typeck 编译拒〕：`%+d`/`% d` 旗标无效（按无旗标输出）；`%.1s` 忽略精度（整串输出）；`%c` 高位字节经 char 通道两字节化 | 不一致 | `host/host_format.mbt`（oracle 既有偏差照搬） |
| 2 | **atof 整串解析失败返回 0.0**〔DIFF-LIB-ATOF-01，2026-09-30 探针实锤〕：`atof("12abc")` 得 0.0，C 语义取前缀应得 12.0 | 不一致 | `host/host_convert.mbt` |
| 3 | **fprintf 到自定义 FILE\* 不落盘**〔DIFF-LIB-FPRINTF-01，2026-09-30 探针实锤〕：非 stderr 通道的自定义文件写入静默丢弃 | 不一致 | `host/host_io.mbt`（VFS 批裁定照搬） |
| 4 | **fgets/fread 文本模式 CRLF 伸缩不分模式**〔DIFF-VFS-CRLF-01〕：二进制读写也做 `\r\n`↔`\n` 转换 | 不一致 | `host/vfs.mbt`（既有偏差登记） |
| 5 | **ctype 域外按原值比较**〔DIFF-LIB-CTYPE-01，retest——2026-09-30 四探针两侧一致，差异面待定位或撤销〕：部分 ctype 函数对域外输入返回恒 0 的比较形态 | 不一致 | `host/host_ctype.mbt`（既有差异照搬不修） |
| 6 | **strncpy/strcat 族边界行为按 oracle 现状**〔DIFF-LIB-STRNCPY-01〕：负 n 补零到尾等界内软夹紧形态与 C 有出入 | 不一致 | `host/host_string.mbt` |
| 7 | **多行宏规范反向漂移**（DIFF-PREPROC-MULTILINE-01）**——MoonBit 侧从未有此缺陷 + 规范已修正（2026-09-30 实测 + 用户审阅补 oracle 对照）**：蓝图 §⑦ 记载的「不支持」方是 **Rust oracle**（实测 vitro_cli 编译失败 E2005）；MoonBit 独立 pass 天然支持（探针输出正确）= vitro_better 分叉（carry_over=drop，无欠账）；规范 §表格 已更正为「已支持」 | MoonBit 侧 Clang 一致；oracle 不一致（E2005） | 台账在册（防将来以 oracle 为真值判 MoonBit 错） |
| 8 | **libc 头文件存根声明冲突**（N3/N4）〔DIFF-LIBC-STUB-CONFLICT-01，N3 行为面 2026-09-30 探针实锤：`int n = printf(...)` 报 E3004 vs Clang 通过〕：内置 puts/printf 声明与用户 include 的 stdio.h 存根冲突场景 | 无 Clang 对应 | `libc/libc.mbt`（S8 台账收编） |
| 9 | **cmd/run 出口层 ≥0x80 字节双重 UTF-8 编码**〔DIFF-EXIT-STDOUT-ENCODE-01——本台账批新实锤（2026-09-30 探针：128/200/255 三点全中，<0x80 正常；host 通道白盒锚正确、出口层 Bytes→String 折回发生两次）〕：所有 ≥0x80 字节的 stdout 物理输出（putchar/printf %c 等）被双重编码 | 不一致 | `cmd/run` 出口（探针 .shadow_tmp/diff_ledger_probe/putchar_range.c） |

## ② 教学语义设计（有意为之——不是缺陷）

Clang 在这些输入下是**未定义行为或静默错误**；Vitro 的白箱设计把它们变成可教学的确定性诊断。这些条目**不会修**——它们是产品本体。

| # | 条目 | Clang 对照 | 语义 |
|---|---|---|---|
| 1 | **受检访存三缺口转 trap**：NULL 解引用 / UAF 读 / 越界读——Clang UB 或读到垃圾，Vitro 给 E30xx 诊断并停 | 无 Clang 对应（Clang UB） | `memory/check_access` 单入口 |
| 2 | **strcpy/strcat E3070 栈缓冲校验**：写入目标容量校验（堆块容量 + 栈缓冲跨度），越界即停带文案 | 无 Clang 对应（Clang UB） | `host/host_string.mbt` |
| 3 | **memset 等写侧受检**：界内软夹紧（超长截断）+ 越界 trap——oracle 无检形态不继承 | 不一致（有意） | `host/host_memory.mbt`（U5 系列） |
| 4 | **1MB 白箱内存 + 释放隔离区**：全部内存可见可解释、UAF 有教学观察窗口、隔离预算可配 | 无 Clang 对应 | `memory` 包 |
| 5 | **步数/调用深度保险丝 + deterministic 模式**：无限循环给诊断不挂起；时钟恒 0 可回放 | 无 Clang 对应 | vm/gateway config |
| 6 | **扩展关键字（U0#1）**：`fun`/`struct` 字面量等教学扩展在宽松模式可用 | 不一致（有意） | gap 语料域（`keyword_compat`） |

## ③ 与 C 标准 / Clang 的已知差异（架构决定的连带）

白箱 32 位内存模型与教学定位的架构级决定，非实现疏漏。

| # | 条目 | Clang 对照 | 说明 |
|---|---|---|---|
| 1 | **指针 4 字节模型**（DIFF-PTR-4BYTE-01）：`sizeof(int*)`=4，x64 Clang=8 | 不一致（架构） | 1MB 可解释地址空间的连带；C 子集规范已记载 |
| 2 | **putchar(≥128) 单字节语义**（DIFF-LIB-PUTCHAR-01——host 通道 Bytes 化正确；**cmd/run 出口层双编码缺陷新实锤 2026-09-30，转 open**，见①-9）：按 C 字节语义落 1 字节 | **Clang 一致** | Rust oracle 曾重编码为 UTF-8 两字节（oracle 侧缺陷，Vitro 侧正确） |
| 3 | **strpbrk/strspn/strcspn 字节语义**：ASCII 域与 Clang 逐字节一致 | ASCII 一致 | 非 ASCII 域 oracle 侧 lossy 缺陷（Vitro 不继承） |
| 4 | **powi10 e=126 偏离**：10^126 与 IEEE 参考差 1 ulp（显式锁定） | 边缘不一致 | `%g` 极端指数域；633 指数全表对拍仅此一例 |
| 5 | **类型显示不区分 unsigned 变体**：诊断/mangle 层 `unsigned int` 显示为 `int` 轨道 | 不一致（显示层） | `ast/types_render.mbt`（mangle 轨道才区分） |
| 6 | **struct packed 布局**（DIFF-LAYOUT-PACKED-01）：`#pragma pack` 未实现 | 不一致 | §8 台账在册（防线零覆盖，先立 golden） |
| 7 | **二次 fclose 受检 trap**：释放后 FILE\* 再操作给诊断（oracle 返 -1） | 不一致（有意，同②方向） | 分叉锚已设 |
| 8 | **vfs 预设注入**（DIFF-VFS-PRESET-01，clang_direct known 在册）：`fopen("test.txt")` 读教学演示预设（Clang 真读文件系统） | 不一致（教学演示通道） | `known_direct` 已归因 |
