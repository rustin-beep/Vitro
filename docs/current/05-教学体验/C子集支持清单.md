# C 子集支持清单

> E1006「暂不支持的功能」教学卡的指引落点（#260，2026-10-27 建）——学生拿到「请查阅支持清单」后到这里。本页是**导航页**：聚合既有权威文档，不复制其内容（单源不造孪生）；逐项的支持/不支持判定以各权威源为准。

## 我能用什么 C？

**语言主干**（C89/C99/C11）：函数与函数指针、指针与数组、struct/union/enum、typedef、预处理（`#include`/`#define`/条件编译 `#if` 族）、`static`/`const`/`register`、常用运算符与控制流（含 `goto`/标签）、局部变长数组（VLA，运行时分配）、`typeof`、变参函数（`...`）、`_Static_assert`（单参/双参字符串形态）。语法细节与已知差异见[《已知限制与差异》](../07-质量与裁定/已知限制与差异.md)。

**标准库**（stdio/math/string/ctype 等头文件与函数逐项清单）：见[《标准库支持矩阵》](../04-标准库与防线/标准库支持矩阵.md)。

## 什么会报「暂不支持」（E1006）

以下是 E1006 的**实测生产点**（每条经 `vitro compile` 亲验落码，2026-10-27 审阅处置批复验）：

- struct/union **成员声明带存储类说明符**（`struct S { static int x; };`——C11 §6.7.2.1 禁，clang 同判）；
- **enum 初始化器非常量**（`enum E { A = x };`——x 非编译期常量标识符）；
- **整数字面量超出可表示范围**（如 `99999999999999999999LL` 超出 unsigned long long 上限，见 #251 族）；
- `_Static_assert` 的第二参数**非字符串字面量**。

注意：并非所有「未支持面」都会报 E1006——部分扩展语法（如 `#pragma`、`__attribute__`、GNU 语句表达式）在当前版本可能被静默跳过或走其他码（`__attribute__` → E2005、内联汇编 → E3036），触发面以实际诊断为准；完整错误码与教学卡可经 CLI 查询：`vitro api error_catalog`（114 条，含每码的解释/常见原因/修复建议）。
